# Portfolio - Alexandre Pugliese

Portfolio personnel réalisé dans le cadre de ma formation en programmation et de ma recherche de stage.

L'objectif de ce projet est de présenter mon parcours, quelques projets réalisés pendant ma formation ainsi qu'un peu plus sur moi.

## Technologies

Le portfolio est développé avec :

- Angular
- TypeScript
- HTML
- CSS

## Contenu

Le portfolio est composé de plusieurs sections :

- Présentation
- Mes projets
- En dehors du code
- Contact

## Projets présentés

### Awélé

Jeu d'Awélé développé avec une architecture client / serveur.

**Technologies :** Java, Spring Boot, OpenAPI

### Meex

Application de gestion permettant de gérer les clients, fournisseurs, articles, commandes et factures.

**Technologies :** Angular, Java, Spring Boot, PostgreSQL

### Once Upon a Time

Projet personnel actuellement en construction.

L'objectif est de créer une application permettant de gérer une collection de livres, suivre ses lectures et organiser sa bibliothèque.

## Lancer le projet

Cloner le projet :

```bash
git clone LIEN_DE_TON_REPOSITORY
```

Se placer dans le projet Angular :

```bash
cd client/portfolio-client
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet :

```bash
ng serve
```

Le portfolio sera ensuite disponible sur :

```text
http://localhost:4200
```
