# Portfolio - Alexandre Pugliese

Personal portfolio developed with Angular as part of my training in application development.

The goal of this project is to present my profile, my skills and some of the projects I have worked on during my studies and in my personal projects.

## Technologies

- Angular
- TypeScript
- HTML
- CSS

## Content

The portfolio includes:

- A short introduction about me
- The technologies I am currently learning and using
- Some of my development projects
- A more personal section about my interests
- Links to my GitHub and LinkedIn
- Contact information

## Projects presented

### Awélé

An Awélé game developed using a client/server architecture.

**Technologies:** Java, Spring Boot, OpenAPI

### Meex

A management application for clients, suppliers, products, orders and invoices.

**Technologies:** Angular, Java, Spring Boot, PostgreSQL

### Once Upon a Time

A future application for managing a book collection and tracking reading progress.

**Technologies:** Java, Spring Boot, SQL

> This project is currently under development.
